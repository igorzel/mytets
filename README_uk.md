# mytets

[English](README.md)

`mytets` — невелика утиліта командного рядка, яка виводить випадкові фрази з
творів українського письменника й драматурга [Леся Подерв'янського](https://uk.wikipedia.org/wiki/%D0%9B%D0%B5%D1%81%D1%8C_%D0%9F%D0%BE%D0%B4%D0%B5%D1%80%D0%B2%27%D1%8F%D0%BD%D1%81%D1%8C%D0%BA%D0%B8%D0%B9).
Можна отримати одну фразу, вивести список унікальних фраз або вибрати формат
JSON для використання у скриптах. Усі фрази вбудовані в програму, тож для
роботи не потрібні обліковий запис чи підключення до інтернету.

## Встановлення

Рекомендований спосіб — встановити програму зі Snap Store:

```bash
sudo snap install mytets
```

Щоб спробувати останню розробницьку версію замість стабільного випуску:

```bash
sudo snap install mytets --channel=edge
```

Також програму можна встановити за допомогою Go:

```bash
go install github.com/igorzel/mytets/cmd/mytets@latest
```

Якщо після встановлення команда `mytets` не знаходиться, переконайтеся, що
каталог `bin` Go додано до змінної `PATH`.

## Швидкий старт

Вивести одну випадкову фразу:

```bash
mytets one
```

Вивести п'ять унікальних фраз (значення за замовчуванням):

```bash
mytets list
```

Вказати кількість фраз:

```bash
mytets list --count 3
```

За замовчуванням команди виводять звичайний текст. Додайте `--output json`,
щоб отримати дані у форматі JSON для обробки скриптами:

```bash
mytets one --output json
mytets list --count 3 --output json
mytets version --output json
```

Наприклад, команда `mytets one --output json` виводить:

```json
{"message":"Ето кайф, марожено!"}
```

## Команди

| Команда | Дія |
|---------|-----|
| `mytets one` | Вивести одну випадкову фразу. |
| `mytets list` | Вивести до п'яти унікальних фраз. |
| `mytets list --count N` | Вивести до `N` унікальних фраз. |
| `mytets version` | Вивести версію програми. |
| `mytets --help` | Показати доступні команди й параметри. |

Додайте `--output json` до команд `one`, `list` або `version`, щоб отримати
результат у форматі JSON. Щоб переглянути довідку для окремої команди, виконайте
`mytets <команда> --help`.

## Збирання з вихідного коду

Щоб самостійно зібрати виконуваний файл, установіть Go та виконайте:

```bash
git clone https://github.com/igorzel/mytets.git
cd mytets
make build
./bin/mytets one
```

Щоб зібрати й установити локальний Snap-пакунок:

```bash
make snap
sudo snap install ./mytets_*.snap --dangerous
```

## Публікація в Snap Store

Ці інструкції призначені для супровідників проєкту, які публікують нові
версії `mytets` у Snap Store. Виконуйте їх по порядку на новій машині:
кроки 1–3 потрібні лише один раз, крок 4 — це звичайний процес релізу.

### 1. Підготувати середовище збірки (один раз на машину, потрібен `sudo`)

```bash
make setup
```

Це встановлює `snapcraft`/`lxd` та налаштовує LXD. При першому запуску
може з'явитися повідомлення "Log out and back in for lxd group membership
to take effect" — його можна проігнорувати й продовжувати одразу: усі
команди нижче виконуються через `sg lxd`, який підхоплює нове членство в
групі негайно, без повторного входу в систему.

### 2. Увійти в Snap Store (один раз на машину)

Потрібен обліковий запис Snap Store (Ubuntu One), який уже є власником або
співавтором назви Snap `mytets` — якщо ви новий супровідник, спершу
попросіть наявного супровідника додати вас через
https://dashboard.snapcraft.io/, інакше команди з кроку 4 завершаться
помилкою доступу.

```bash
make snap-login
```

`make snap-login` спершу пробує звичайний вхід через системний keyring
(Secret Service / gnome-keyring / KWallet), запитуючи ваші email/пароль/2FA
від Ubuntu One. На машинах без робочого keyring — наприклад, у WSL2 або на
сервері без графічного середовища — snapcraft одразу завершується помилкою
`No keyring found`, і `make snap-login` автоматично переходить на вхід без
keyring, зберігаючи облікові дані у файл `./snapcraft.login` (тримайте
його в секреті; він уже доданий до `.gitignore`). У будь-якому разі всі
наступні команди `snap-*` нижче автоматично використовують отримані
облікові дані — вручну виконувати
`export SNAPCRAFT_STORE_CREDENTIALS=...` ніколи не потрібно. Якщо файл
`./snapcraft.login` вже існує, повторний запуск `make snap-login` на
машині без keyring нічого не робить; видаліть файл, якщо потрібна повторна
авторизація.

### 3. Зареєструвати назву Snap (уже зроблено, один раз назавжди)

Назва `mytets` уже зареєстрована в Snap Store, тож зазвичай цей крок не
потрібен. Він виконується лише один раз, назавжди, тим, хто першим
зареєстрував назву — повторний запуск завершиться помилкою "name already
taken", тож пропустіть цей крок, якщо тільки не публікуєте під зовсім
новою назвою Snap:

```bash
make snap-register
```

### 4. Опублікувати нову версію

Опублікувати збірку в каналі `edge`:

```bash
make snap-publish SNAP_CHANNEL=edge
```

Перевірити, яка ревізія наразі опублікована в кожному каналі:

```bash
make snap-status
```

Пізніше наявну ревізію можна перевести, наприклад, у стабільний канал:

```bash
make snap-release REVISION=<store-revision> SNAP_CHANNEL=stable
```

Команда `make snap-status` показує лише ревізію, яка наразі активна в
кожному каналі. Щоб побачити всі завантажені ревізії, зокрема ті, що ще
не опубліковані в жодному каналі:

```bash
make snap-revisions
```
